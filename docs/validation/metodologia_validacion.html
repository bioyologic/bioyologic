Validation methodology

Same plates, same photos: people vs Bioyologic vs other software

1

Prepare plates in the lab

  • Spread plate, 0.1 mL
  • Serial dilutions 10⁻⁴ to 10⁻⁶
  • Minimum 3 plates; ≥ 10 for statistics
  • Incubate 24 h at 37 °C
→
2
📷

One standardized photo per plate

  • Inside the lighting box
  • Same phone, height and light
  • Plate closed, coded (P01, P02…)
→
3

Count every plate with each method

✋ Manual count 3 blind observers = reference
🦠 Bioyologic app, same photo
💻 OpenCFU same photo
💻 Second software e.g. ImageJ / Fiji

Record the count and the time per plate for each method.

→
4
📊

Compare and test

  • % error vs manual, MAPE
  • Bias and Bland–Altman limits
  • Correlation (r, Lin's CCC)
  • Friedman + Wilcoxon (p < 0.05)
  • Equivalence: within ±5 %?
AccuracyIs Bioyologic's error ≤ 5 % (Must have M1)?
ComparisonIs its error significantly lower than OpenCFU's?
AgreementDoes it agree with people as well as people agree with each other?
SpeedHow many seconds per plate vs counting by hand?
